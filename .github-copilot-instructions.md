# GitHub Copilot Instructions for AboutMe Portfolio Project

## Communication Guidelines
- **Always ask clarifying questions** when instructions are unclear or ambiguous
- Ask as many questions as needed until the task can be carried out effectively
- Do not make assumptions about user preferences without confirming first

## Technical Requirements
- **Framework**: Node.js with TypeScript
- **Styling**: Tailwind CSS
- **Animations**: GSAP (use to full potential - 3D transforms, scroll triggers, complex animations)
- **Templating**: Nunjucks
- **Deployment**: GitHub Pages
- **Responsive**: Mobile-first design, looks great on both mobile and laptop

## Content Management
- Use data files (JSON/TypeScript) for easy content updates
- Keep content separate from templates for maintainability

## Package Management
- **Always verify package versions** using MCP servers before adding dependencies
- Keep `package.json` up to date with latest stable versions
- Check npm for latest versions of:
  - TypeScript
  - Tailwind CSS
  - GSAP
  - Nunjucks
  - Build tools (Vite/Webpack/Parcel)
  - Any other dependencies

## Design Principles
- **Aesthetic**: Creative, animated, modern, impressive
- Use 3D transforms and GSAP animations extensively
- Mobile-first responsive design
- Smooth scroll animations and page transitions
- Interactive hover effects
- Professional yet creative appearance

## Development Approach
- **Iterative development**: Build in increments, test frequently
- Track progress in `PROGRESS.md`
- Commit working features regularly
- Ensure cross-browser compatibility
- Optimize for performance despite heavy animations

## Quality Standards
- Clean, well-documented TypeScript code
- Accessible markup (ARIA labels, semantic HTML)
- SEO-friendly structure
- Fast load times
- Smooth 60fps animations
- No layout shifts or janky scrolling
